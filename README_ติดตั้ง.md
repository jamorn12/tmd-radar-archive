# ทันฝน — หน้าเว็บใหม่ (V5) วิธีอัปขึ้น GitHub โดยไม่ใช้ PowerShell

## 1. ลากไฟล์เข้า repo

เปิด https://github.com/jamorn12/tmd-radar-archive → **Add file → Upload files**
ลากสองโฟลเดอร์นี้เข้าไปพร้อมกัน

    radar_archive/     basemap.py · webapp.py · cli.py · web/app.html
    docs/              index.html · base_dark.png · base_light.png · ไอคอน · ผล nowcast ชุดแรก

`cli.py` ทับของเดิม (ตั้งใจ — เพิ่มคำสั่ง `basemap` กับ `site`)
ไฟล์ที่เหลือเป็นของใหม่ทั้งหมด ไม่ทับอะไร

ถ้าเคยอัปเวอร์ชันก่อนหน้าไปแล้ว **ลบสองไฟล์นี้ทิ้งด้วย** เพราะเปลี่ยนไปใช้ PNG แล้ว

    docs/base_dark.jpg
    docs/base_terrain.jpg

commit message: `web: รื้อ UI ใหม่ แผนที่ซูมได้ + แถบฝน 105 นาที`

## 2. แก้ workflow ในเว็บ (โฟลเดอร์ .github ลากไม่ขึ้น)

ไปที่ `.github/workflows/archive.yml` → กดดินสอ → ลบทั้งหมด →
วางเนื้อหาจาก `_workflow/archive.yml` ในแพ็กนี้ → commit

ที่เพิ่มมามีสองจุด

- step ใหม่ **Nowcast (extrapolation, 60 min)** ตั้ง `continue-on-error: true`
  เพราะ nowcast ล้มไม่ควรทำให้การเก็บคลังล้มตาม คลังคือของที่กู้คืนไม่ได้
  ส่วน nowcast รอบหน้า (อีก 15 นาที) คำนวณใหม่ได้อยู่แล้ว
- `git add -A data/` → `git add -A data/ docs/nowcast/`

## 3. เปิด GitHub Pages

Settings → Pages → Source **Deploy from a branch** → Branch **main** / **/docs** → Save

รอ 1–2 นาที เว็บจะขึ้นที่

    https://jamorn12.github.io/tmd-radar-archive/

บนมือถือกด แชร์ → Add to Home Screen (Chrome Android: เมนู → ติดตั้งแอป)
มี manifest กับไอคอนให้แล้ว

## คำสั่งที่ใช้ทีหลัง

    python -m radar_archive.cli --station PHS basemap --n 80
        สร้าง docs/base_dark.png + base_light.png ใหม่จากภาพ raw
        **ยิ่งคลังโตยิ่งสะอาด** — ควรรันซ้ำเมื่อมีภาพข้ามหลายวันแล้ว
        เพราะก้อนฝนที่ค้างอยู่ที่เดิมนาน ๆ จะหลุดออกจากค่ามัธยฐานหมด

    python -m radar_archive.cli site
        ประกอบ docs/index.html ใหม่ (รันทุกครั้งที่แก้ radar_archive/web/app.html)

    python -m radar_archive.cli site --demo tanfon_demo.html
        ได้ไฟล์เดียวจบที่ฝังข้อมูลมาด้วย เปิดจากเครื่องตรง ๆ ได้ ไม่ต้องมีเซิร์ฟเวอร์

## แผนที่ฐานมาจากไหน

ไม่ได้โหลด shapefile จากที่อื่น แต่ดึงจาก **ภาพ TMD เอง**
ฝนเคลื่อนที่ แผนที่ไม่เคลื่อน — ค่ามัธยฐานรายพิกเซลข้ามหลายสิบเฟรมจึงเหลือแต่แผนที่
แล้ววาร์ปด้วยสมการเดียวกับที่ใช้วาร์ป echo ผลคือลงทะเบียนตรงกันโดยอัตโนมัติ

จากนั้นไม่ได้เอาภาพนั้นมาใช้ตรง ๆ แต่ **แยกเป็นสามชั้น** ก่อน

| ชั้น | หามาจาก |
|---|---|
| terrain | ภาพที่ผ่าน median filter → เหลือแต่เงาภูมิประเทศ |
| border  | เส้นที่ **มืด** กว่าพื้นรอบข้าง = ขอบเขตการปกครอง |
| water   | เส้นที่ **น้ำเงิน** กว่าพื้นรอบข้าง = แม่น้ำและอ่างเก็บน้ำ |

ส่วนที่ **สว่าง** กว่าพื้นรอบข้าง (ชื่อเมืองภาษาอังกฤษ ป้ายระยะ จุดเมือง) ทิ้งทั้งหมด
เพราะเราวาดเองเป็นภาษาไทยและคมกว่าทุกระดับซูม
ส่วนวงรัศมีน้ำเงินกับเส้นรัศมีแดงลบด้วยหน้ากากเชิงเรขาคณิต เพราะรู้ตำแหน่งเป๊ะอยู่แล้ว

ที่ต้องแยกเป็นชั้นแทนที่จะย้อมสีทั้งแผ่น เพราะเส้นบนแผนที่ TMD สว่างไม่เท่ากัน
ขอบจังหวัดเป็นเส้น**ดำ**บนพื้นเขียวมะกอก ส่วนแม่น้ำเป็นเส้น**สว่าง**
ถ้าแม็ปตามความสว่างอย่างเดียว ขอบจังหวัดจะหายไปทั้งหมด

ได้ผลลัพธ์เป็นภาพเวกเตอร์เทียม ย้อมเป็นธีมสว่างหรือมืดก็ได้จากชุดเดียวกัน
